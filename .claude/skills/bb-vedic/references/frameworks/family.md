# 家庭 / 父母 / 祖傳業力類

涵蓋：跟父母關係、家族業力、繼承、要不要照顧父母、家庭壓力源。

## 跟父母關係類

必須分析：
1. **D-12 Dwadasamsa 特殊力量行星** → 父母 / 祖傳給的命運底牌
   - 凶星（Mars / Saturn / Rahu / Ketu）廟旺 = 家族壓力大但有力量可承接
   - 吉星（Jupiter / Venus / Moon）廟旺 = 家族祝福 / 福報強
2. **太陽 dignity + 宮位**（父親自然徵象星）→ 跟父親的能量關係
   - 太陽落陷 = 父權 / 父親形象弱化或衝突
   - 太陽高揚 / 廟旺 = 父親是強支撐源
3. **月亮 dignity + 宮位**（母親自然徵象星）→ 跟母親的情感關係
   - 月亮落陷 = 母系情感連結困難
   - 月亮 Neecha Bhanga = 表面弱但深處有力，關係會反轉
4. **4 宮（母親 / 家庭根基）+ 4 宮主** 位置和行運 → 母系 / 家庭根基穩不穩
5. **9 宮（父親 / 法性 / 教導）+ 9 宮主** 位置和行運 → 父系 / 教導傳承的品質
6. **Rahu / Ketu 軸線** 跟 4/9 宮的關係 → 家族業力的核心張力（Rahu 該宮位 = 還沒解的功課；Ketu 該宮位 = 前世已熟悉的模式，這輩子要放下）

## 祖傳業力 / 繼承 / 家族模式類

必須分析：
1. **D-12 整體分布**（吉凶星集中度）→ 祖先傳下的命運品質
2. **D-40 Khavedamsa**（如有）→ 母系專屬業力
3. **D-45 Akshavedamsa**（如有）→ 父系專屬業力 + 性格深層
4. **木星位置**（家族福報）+ **土星位置**（家族責任 / 限制）
5. **2 宮（家族財產 / 言說傳承）** + **8 宮（繼承 / 隱藏資源）** → 物質繼承面向
6. **Dasha 階段** → 家族重大事件（父母健康、繼承、重要決定）的觸發期

## 要不要照顧父母 / 家庭責任類

必須分析：
1. **4 宮主 / 9 宮主** 的 dignity → 父母面向的責任輕重
2. **土星跟 4/9 宮的關係** → 紀律型責任的觸發
3. **Saturn 行運 4 宮** → 家庭責任壓力放大期（讀 `行星換座事件`）
4. **AmK 是否跟 4/9 宮有關** → 家庭責任是不是事業必經之路
5. **6 宮（服務 / 義務）** 狀態 → 「應該」型壓力是否會變成負擔

時機：
- Saturn 行運 4 宮 = 母系 / 家庭責任高峰，要主動承接不要拖
- 木星行運 4 宮 = 家庭和解 / 修復的窗口
- Rahu 行運 4 宮 = 突如其來的家庭變化（搬遷 / 父母健康）

### 紅線

- ❌ 不要從 D-12 單張下「跟父母緣薄」結論 — 必看太陽 / 月亮 + 4/9 宮
- ❌ 不要把「家族業力」講得宿命 — 業力盤是「給你看課題在哪」，不是「定你的結局」
- ❌ Rahu 在 4/9 宮 ≠ 父母不好，是「跟父母的功課還沒做完」
- ❌ 不要在沒問家庭關係時主動爆 D-12 凶相 — 對使用者是雜訊也是恐嚇
