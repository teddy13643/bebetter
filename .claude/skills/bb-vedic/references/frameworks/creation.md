# 創造 / 子女 / IP / 內容類

涵蓋：side project、內容創作、IP / 商品、課程、藝術產出、生育判斷。

## 創造 / IP / 內容創作類

必須分析：
1. **D-7 Saptamsa 特殊力量行星** → 創造產出的天花板（Venus 強 = 美感型；Mercury 強 = 內容型；Jupiter 強 = 智慧型；Sun 強 = 個人品牌型）
2. **5 宮（創造、表演、投機）+ 5 宮主** → 創造能量本質
3. **3 宮（自我推進、短內容、社群）+ 3 宮主** → 持續產出的動能
4. **木星**（智慧 / 子女自然徵象星）本命位置 → 「智慧型創造」的福報底盤
5. **金星 + 水星** → 美感（Venus）+ 表達 / 寫作（Mercury）
6. **AK 或 AmK 是否落在 3 / 5 宮** → 靈魂是否真的把能量押在「創造產出」這條路
7. **Dasha lord** 跟 5 宮 / 3 宮 / Mercury / Venus 的關係 → 現在是不是發功時段

### 變現判斷（IP 能不能賣錢）

不要只看 D-7，要 **D-7 + D-2 + 11 宮** 三角校對：
- **D-7 強** → 做得出來
- **D-2 強**（Hora 行星分布）→ 賺得到錢
- **11 宮 SAV ≥ 30**（收益生態系）→ 收入網絡會接住
- 三者只強 1-2 個 → 「做得出但賣不掉」/「賣得掉但做不出規模」

### 時機

- 木星行運 5 宮 = 創造 / 發布 / 量產的高峰
- 木星行運 3 宮 = 短內容 / 社群推進的高峰
- 水星行運 5 宮（順行）= 寫作 / 製作的順流
- 水星逆行 = 不要發布、適合修稿和重做

## 子女 / 生育類

必須分析：
1. **D-7 Saptamsa 整體狀態**（凶星集中 = 子女緣弱 / 過程艱辛；吉星集中 = 緣強）
2. **5 宮 + 5 宮主** 的 dignity 和行運
3. **木星本命位置 + 行運**（自然徵象星）
4. **AmK 是否跟 5 宮有關** → 子女是否在這輩子事業 / 靈魂主軸內
5. **Dasha lord** 跟 5 宮 / 木星的關係 → 現在是不是受孕窗口

時機：
- 木星行運 5 宮 / 9 宮 = 受孕高機率窗口
- Saturn 行運 5 宮 = 延遲 / 困難期，不要硬催
- Rahu 行運 5 宮 = 非常規方式（試管 / 領養 / 意外）
