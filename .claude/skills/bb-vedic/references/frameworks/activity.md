# 活動 / 興趣類 + 運動 / 鍛鍊類

## 活動 / 興趣類

**判斷流程（重要，順序不能反）**：
1. 先看使用者有沒有具體說想做什麼（包括對話中的隨口偏好、抗拒、好惡）— 有就先驗證**那個方向**，不要繞遠路推「盤面最佳解」
2. 沒有具體偏好時才從盤面推方向
3. 推薦時主動標註：這是基於「盤面最佳契合」還是「你說的興趣」— 兩者不同要分清楚

必須分析：
1. **3 宮（興趣、勇氣嘗試新事物）** 和 **5 宮（創意表達、娛樂）** 的狀態
2. **金星** → 藝術、舞蹈、美學、樂器、視覺類活動
3. **火星** → 運動、競技、體能活動
4. **水星** → 學習型活動、語言、寫作
5. **D-3 Drekkana** 的特殊力量 → 勇氣和興趣天賦
6. **行運** 在 3 宮或 5 宮的吉凶 → 今年適不適合開始

### 特殊宮位 / 組合的優先項（推薦活動時必須考慮）

| 盤面條件 | 該優先推什麼類型 |
|---------|-------------|
| **2 宮多星（3+ 顆）** | **聲音 / 言說型活動優先** — 聲樂、演講、podcast、配音、口語藝術。樂器類退為次選 |
| **AK 在 2 宮** | 同上 + **加倍權重** — 靈魂主管道是「用聲音 / 累積價值」 |
| **AK 在 3 宮** | 短內容、寫作、社群、技藝類 |
| **AK 在 5 宮** | 創作、表演、子女教育、投機型 |
| **3 宮 Venus / Venus 廟旺** | 藝術技藝（樂器、繪畫、舞蹈） |
| **5 宮 Mercury / Sun** | 創意表達（寫作、演出、戲劇） |
| **D-3 Venus 廟旺** | 藝術天賦本身強，可學任何結構性藝術 |
| **Venus 在土象星座**（Cap/Tau/Vir） | 結構性、長期練的藝術（古典、傳統樂器、聲樂）— 不是即興型 |
| **Saturn 廟旺/高揚** | 需要紀律的長期技藝（古典、體系化訓練、傳統工藝） |

### 紅線

- ❌ 不要因為「跟主軸串聯最強」推薦使用者明顯沒興趣的方向（例：Vedic 主題不代表非學印度樂器不可、財運主題不代表要學投資）
- ❌ 不要先列「最佳解」再說「但你也可以選別的」— 應該倒過來：先確認偏好，再從偏好出發驗證盤面
- ❌ 不要推「年齡限制」的刻板印象（例：35 歲學樂器太晚）— 先看盤面，年齡只是一個條件不是否決理由

## 運動 / 鍛鍊類

必須分析（4 點交叉看）：
1. **D-27 Saptavimsamsa Mars** → 運動天賦本質（Mars 廟旺/高揚 = 體能底子強；落陷 = 容易受傷）
2. **D-3 Drekkana Mars + Saturn** → 訓練的「動作型態偏好」（Mars 在火 = 爆發；土 = 耐力；水 = 韻律；風 = 靈巧）
3. **D-1 Mars 宮位 + 力量** → 對抗 vs 獨練（Mars 7 宮落陷 = 不要對抗 / 團體競技）
4. **D-30** → 弱點集中部位（行星集中的星座 → 對應身體系統要保護）

判斷流程：
- 先問偏好 → 有偏好就驗證該運動跟上面 4 點是否衝突
- 沒偏好 → 從盤面推 2-3 個對的方向（重訓 / 瑜伽 / 游泳 / 攀岩 / 武術 / 跑步...）

### 紅線

- ❌ Mars D-1 落陷 + 7 宮 → 不推對抗性團體運動（籃球 / 足球 / 對打）
- ❌ Mars 落陷 → 不推 HIIT / Crossfit / 高強度爆發
- ❌ D-30 多顆行星集中某星座 → 對應身體部位要避免硬負荷（例：金牛 = 頸 / 肩 / 上背）
