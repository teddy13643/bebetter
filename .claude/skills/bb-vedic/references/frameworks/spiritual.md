# 靈性修行類 + 前世 / 業力類

## 靈性修行 / 玄學興趣類

必須分析：
1. **D-20 Vimsamsa** 的特殊力量行星 → 修行的天生偏好（Jupiter=哲學、Sun=瑜伽、Moon=冥想、Saturn=苦行）
2. **9 宮（法性）和 12 宮（出世）** 的守護星
3. **Ketu** 位置 → 前世修行軌跡
4. **木星行運** → 適合開始新法門的時機（讀 `行星換座事件` 看木星何時進 9/12 宮）

## 前世 / 業力類

必須分析：
1. **Atmakaraka（AK）** 所在宮位 / 星座 → 靈魂這輩子最要面對的核心議題（AK 落陷 = 業障重的領域、AK 高揚 = 帶福報來）
2. **D-60 Shastiamsa** 的行星分布 → 累世帶來的細部命運（特別看 AK 在 D-60 的位置）
3. **Ketu 位置**（D-1 + D-60）→ 前世已完成的領域
4. **Rahu 位置** → 這輩子要學的新功課
5. **9 宮木星**（如有高揚 / 廟旺）→ 前世福德資產
6. **D-9 木星** → 靈魂層級智慧
