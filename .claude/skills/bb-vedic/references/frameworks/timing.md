# 時機類 + 策略類 + 居住類

**簡化流程**：這三類不跑「4 層三角校對」，直接看 Dasha + 行星換座 + monthly_gochar。

## 時機類（「何時」「幾月」）

時機判斷的優先順序：
1. **Dasha 交接** 是最大的時間分界線 → 交接前後的策略完全不同（讀 `dasha.目前` vs `dasha.target_year_中`，lord 不同 = 今年內會交接）
2. **`行星換座事件`** → 慢行星何時進入新星座，機會領域 / 壓力領域轉換的關鍵日期
3. **`逐年分析[].monthly_gochar`** → 把「下半年」精確到「具體哪個月」
   - 查問題對應宮位的星座，看 SAV 分數（≥30 = 重點宮位，活動多）
   - 查相關行星 transit 進入哪個星座 + 該行星 BAV 在那個星座的分數
   - 例：問升職 → 10 宮星座 SAV + 木星 transit 進入時的 BAV 分數
4. **木星換座月份** → 機會領域轉換
5. **土星換座月份** → 壓力領域轉換
6. **火星行運** → 短期行動力 / 衝突的觸發

## 策略類（主動 vs 被動）

從上升守護星位置 + 火星 / 金星強弱判斷天生傾向（詳見 `relationship.md`「主動 vs 被動判斷」段落）。

時機：
- 大限 lord 是 Mars / Sun / Saturn → 主動推進是這幾年的主旋律
- 大限 lord 是 Moon / Venus / Jupiter → 被動接收 / 等資源送上門
- 行運 Rahu 在 1 宮 → 突破舒適圈的衝動會被啟動

## 居住類（搬家 / 買房 / 裝修）

必須分析：
1. **D-4 Chaturthamsa** 的特殊力量行星 → 不動產潛能
2. **4 宮主** 的本命位置和行運（讀 `monthly_gochar.從上升宮位` 看哪幾月 4 宮主進到吉位）
3. **木星行運 4 宮** → 適合買房 / 搬家
4. **火星 / 土星行運 4 宮** → 結構壓力，先別動
5. **Rahu 行運 4 宮** → 突如其來的搬遷信號（讀 `行星換座事件`）

時機：
- 搬家最佳期 = 4 宮主吉位 + 木星行運非凶位的月份
- 動工 / 裝修 = 火星行運不在 4 宮的月份
