# 財運類

必須分析：
1. **2 宮（正財）和 11 宮（收入）** 的守護星和行運
2. **D-2 Hora** 的行星分布 → Leo 多=靠自己、Cancer 多=靠儲蓄 / 家族
3. **木星** 本命位置和行運 → 財富擴張的管道
4. **土星** 在 2 宮或 11 宮 → 財務紀律或壓力
5. **Rahu** 如果在 2 宮或 11 宮 → 非常規財源（但有風險）

投資判斷：
- 土星行運 5 宮 = 不適合投機
- 木星行運 2 宮或 11 宮 = 正財運好（讀 `行星換座事件` 確認木星何時進到吉位）
- Rahu 行運 2 宮 = 容易被非常規投資吸引（要小心）

買房 / 不動產：
- 看 D-4 Chaturthamsa 的特殊力量行星 → 不動產潛能
- 4 宮主行運狀態 → 何時適合動
- 火星 / 土星行運 4 宮 → 短期內結構性壓力，先別動
