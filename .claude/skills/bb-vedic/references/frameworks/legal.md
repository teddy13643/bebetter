# 法律類

**簡化流程**：法律類問題不跑「4 層三角校對」，直接走 6/7 宮對比 + 火星 / 土星行運。

必須分析：
1. **6 宮（訴訟）** 和 **7 宮（對造）** 的行運（讀 `monthly_gochar.從上升宮位`）
2. **火星** 的位置和行運 → 衝突能量
3. **土星** 的行運 → 是否有利於打持久戰
4. **D-10 土星** 如果在天秤 / 摩羯 / 水瓶 → 法律事務的天生底牌
5. **Rahu** 如果碰到 6 宮或 7 宮 → 法律糾紛的觸發

勝敗判斷：
- 6 宮主比 7 宮主強 → 你有優勢
- 土星行運支持（3/6/11 宮吉位）→ 耐得住
- 火星行運 7 宮 → 對手也很兇，短期內不好收場

時機：
- 開庭 / 簽約最佳期 = 木星行運吉位 + 火星不在 7 宮的月份
- 撤告 / 和解時機 = Rahu 換座離開 6/7 宮後（讀 `行星換座事件`）
