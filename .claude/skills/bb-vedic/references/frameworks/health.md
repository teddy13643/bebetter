# 健康 / 災厄類

必須分析：
1. **D-30 Trimsamsa** 的特殊力量行星 → 體質弱點和心理盲點
2. **D-6 Shashtamsa**（疾病、債務、敵對） → 慢性病的形成模式、容易卡住的健康循環。D-30 看「體質弱在哪」，D-6 看「疾病如何反覆」
3. **D-8 Ashtamsa**（壽命、突發事件、意外） → 突發災禍的風險形態、手術 / 開刀的承受力。Mars / Saturn / Rahu 在 D-8 凶位要警示意外風險
4. **D-27 Saptavimsamsa Mars / Sun / Saturn** 的位置 → 體能本質、自癒力、結構支撐力
5. **6 宮（疾病）和 8 宮（手術、慢性病）** 的守護星和行運（讀 `monthly_gochar.從上升宮位`）
6. **本命月亮力量** → 心理穩定度
7. **行運土星** → 慢性壓力源
8. **Rahu / Ketu 軸線** 在 D-30 → 心理執著的核心張力

不講「會生什麼病」，講「容易在哪個層面失衡」+「該預防什麼模式」。

時機（手術 / 開刀 / 體檢）：
- 避開 6/8/12 宮行運多的月份
- 避開火星 / 土星合月亮的月份
- 木星行運 1 宮或 5 宮 = 自癒力強的時段
