# 感情類

必須分析：
1. **7 宮守護星** 的本命位置 → 你吸引什麼類型的人
2. **Darakaraka（DK）** 所在星座 / 宮位 → 配偶的氣質類型（DK 是 Char Karaka 度數最低那顆）
3. **D-9 Navamsa 金星** → 骨子裡要的感情品質
4. **D-9 七宮主 + DK 在 Navamsa 的位置** → 配偶特質線索（兩個對照看）
5. **行運土星** 如果在 5 宮或 7 宮 → 感情壓測期（讀 `逐年分析[].monthly_gochar` 看哪幾月 Saturn 在 5/7 宮）
6. **Dasha lord** 跟金星 / 7 宮的關係 → 這段期間感情的底色
7. **上升守護星的位置** → 主動 vs 被動的天生傾向
8. **3 宮（日常圈）、5 宮（戀愛）、7 宮（婚姻）** 的行運狀態（讀 `monthly_gochar.從上升宮位`）

主動 vs 被動判斷：
- 上升守護星在 1/3/5/10 宮 → 偏主動
- 上升守護星在 4/7/9/12 宮 → 偏等待
- 火星強且跟 7 宮有關 → 主動出擊型
- 金星強且在接收宮位 → 被追比較順
- 緣分來源看 7 宮主和金星所在宮位（3 宮=日常圈、9 宮=遠方/學習場合、11 宮=社交圈）
