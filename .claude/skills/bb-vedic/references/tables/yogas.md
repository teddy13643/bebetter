# Yoga 主清單（速查表）

> sub-agent 解讀 yoga 時的對照表。每個 yoga 包含：偵測條件、分類、強度、解讀模板、觸發 Dasha。
> 偵測在 API 端 (`core/vedic_yogas.py`)，這份檔案是給 sub-agent 看怎麼跟用戶解讀。

---

## 強度分級

| 級別 | 標誌 | 意義 |
|------|------|------|
| ⭐⭐⭐⭐⭐ | 命格頂 | 5 大人物 / Maha Bhagya / Akhanda 級，整體格局決定性 |
| ⭐⭐⭐⭐ | 主格局 | Raja / Dhana 主流組合 |
| ⭐⭐⭐ | 加分 | 一般吉 yoga |
| ⭐⭐ | 補強 | 條件型，要其他配合 |
| ⚠️ | 警示 | 凶 yoga |

## 主格局 vs 次格局（呈現時分組用）⭐ 必看

報告呈現時**必須分組**，避免「弱 yoga 充人頭」誤導用戶以為自己 yoga 多。

### 主格局（命格決定性，少見）

- 所有 **Raja Yoga**：Kendra-Trikona / Neecha Bhanga / Vipareeta / Dharma-Karmadhipati
- **Pancha Mahapurusha**（5 大人物）
- **Maha Bhagya**
- **Saraswati / Kalanidhi**（條件嚴的學識 yoga）
- **Kala Sarpa**（命格特殊）
- **Lakshmi**（嚴格的財富 yoga）
- **Chandra-Mangal**（核心財富 yoga）
- **Budha-Aditya**（核心智慧 yoga，特別在 2/5/9/10/11 宮）
- **Gajakesari**（月木角宮關係）
- **Adhi**（3 顆吉星到月亮 6/7/8 全到位）
- **Maha Parivartana**（角宮主 + 三方宮主互換）

### 次格局（加分 yoga，容易形成）

- **月亮兩側 yoga**：Sunapha / Anapha / Durudhara / Vasumati
- **太陽兩側 yoga**：Vesi / Voshi / Ubhayachari
- **單組宮主 Dhana yoga**：1-2 / 1-5 / 1-9 / 1-11 / 2-5 / 2-9 / 2-11 / 5-9 / 5-11 / 9-11
- **Kahala**（4-9 主合，輔助）
- 其他 **Parivartana**（非 Maha Parivartana）

### 警示（凶 yoga / Dosha）

**重級警示**（命格有明確挑戰主題）：
- **Mangal Dosha**（婚姻挑戰）
- **Guru Chandal Yoga**（信仰 / 長輩價值衝突）
- **Pitra Dosha**（祖先業力）
- **Vish Yoga**（情緒沉重 / 抑鬱傾向）
- **Karako Bhava Nashaya** (Venus in 7 / Jupiter in 5)

**輕級警示**（局部影響）：
- Kemadruma / Shakata / Daridra
- **Grahan Yoga** (Moon-only)
- **Mars-Saturn Conflict**
- **Combust（焦傷）**（個別行星力量受損）

**呈現規則**：報告中**警示永遠列出**，不要因為「不好聽」省略。沒有破解條件的警示要明寫「無破解，影響長期存在」。

### 重複偵測規則

某些 yoga 是**同一個行星連結**從不同角度被算兩次：

| 同一連結 | 雙重身份 |
|---------|---------|
| 1L + 9L 互望 | Mars-Moon Kendra-Trikona Raja（王者）+ Dhana 1-9（財富） |
| 7L + 9L 連結 | 可能同時觸發 Raja + Dhana |

**呈現規則**：列表中標註「共享同一行星連結」，不要當兩個獨立 yoga 計入「主格局數量」— 算一個就好，但兩面意義都寫。

### 5+ 組 Dhana 的特殊規則

如果偵測到 ≥5 組 Dhana yoga 同時成立 = **獨立列為「Dhana 多組合計」主格局** — 多財路本身就是一種命格。次數少（< 3 組）就維持次格局。

## 五大人物（Pancha Mahapurusha）⭐⭐⭐⭐⭐

5 顆星其中之一在角宮 (1/4/7/10) + 高揚 / 廟旺，命主直接帶該行星天賦。

| Yoga | 行星 | 主題 | 解讀模板 |
|------|------|------|---------|
| Ruchaka | Mars | 戰士 | 體能 / 領導力 / 軍人 / 運動員 / 外科醫生氣質 |
| Bhadra | Mercury | 智者 | 表達 / 商業 / 學識 / 邏輯思考突出 |
| Hamsa | Jupiter | 智慧 | 教導 / 宗教 / 哲學 / 顧問型權威 |
| Malavya | Venus | 美感 | 藝術 / 美感 / 享受 / 魅力 / 創作 |
| Shasha | Saturn | 領袖 | 紀律 / 權威 / 長壽 / 大器晚成型 |

**解讀重點**：直接是「天賦級 + 容易兌現」，因為 5 大人物 yoga 不需要 Dasha 啟動就在外顯。

## 月亮系 Yoga

### Gajakesari ⭐⭐⭐
**條件**：月亮和木星互為角宮（差 0/3/6/9 房）
**解讀**：智慧 / 聲望 / 福德 / 影響力 — 這個人的氣場讓人信服

### Sunapha ⭐⭐⭐
**條件**：月亮 2 宮（除太陽外）有行星
**分類**：財富
**解讀**：靠**自身努力**累積財富 / 智慧 / 聲譽 — 不是天上掉下來，是慢慢存出來

### Anapha ⭐⭐⭐
**條件**：月亮 12 宮（除太陽外）有行星
**解讀**：聲譽 / 外型出色 / 精神生活充實 / 適度享受

### Durudhara ⭐⭐⭐⭐
**條件**：月亮兩側（2 宮 + 12 宮）都有行星
**解讀**：物質豐裕 / 感官享受 / 舒適生活 / 貴人輔助 — 比 Sunapha + Anapha 加總更強

### Adhi ⭐⭐⭐⭐
**條件**：水、木、金都在月亮 6/7/8 宮
**解讀**：領導力 / 富裕 / 長壽 / 被尊敬

### Vasumati ⭐⭐⭐⭐
**條件**：水、木、金都在月亮 upachaya 宮（3/6/10/11）
**分類**：財富
**解讀**：持續累積的物質豐裕 — 越老越富，財富透過正當努力穩定增長

### Chandra-Mangal ⭐⭐⭐⭐
**條件**：月亮和火星合相或互望
**分類**：財富
**解讀**：商業敏銳度 / 賺錢動力 / 財富累積能力 — 看得到機會、敢動手

### Kemadruma ⚠️
**條件**：月亮 2/12 宮無行星（除太陽 + 月亮不在角宮）
**解讀**：情緒孤獨 / 內在不安 / 起伏大 / 難以從他人獲得情感支持
**破解**：月亮在角宮 / 與吉星合相可破

### Shakata ⚠️
**條件**：月亮和木星互為 6/8 宮
**解讀**：人生起伏明顯 / 福氣斷續 / 智慧與情緒拉扯
**破解**：木星強勢可大幅減輕

## 太陽系 Yoga

### Budha-Aditya ⭐⭐⭐⭐
**條件**：太陽 + 水星合相 + 距離 > 14°（未焦傷）
**分類**：智慧 / 表達
**解讀**：智慧 / 聲望 / 表達力 / 學識被認可 — 在 2/5/9/10/11 宮特別強

### Vesi ⭐⭐⭐
**條件**：太陽 2 宮（除月亮外）有行星
**解讀**：言語有分量 / 誠實守信 / 外觀威嚴

### Voshi ⭐⭐⭐
**條件**：太陽 12 宮（除月亮外）有行星
**解讀**：慷慨 / 學識 / 適度的精神享受

### Ubhayachari ⭐⭐⭐⭐
**條件**：太陽兩側（2 宮 + 12 宮）都有行星
**解讀**：富裕 / 地位 / 長壽 / 被尊敬 — 太陽系 yoga 中最強

## Raja Yoga（王者格局）

### Kendra-Trikona Raja ⭐⭐⭐⭐
**條件**：任一角宮主（1/4/7/10）和任一三方宮主（1/5/9）合相或互望
**分類**：王者 / 地位
**解讀**：權力 / 地位 / 領導機會 / 人生格局提升 — 越多組越強

### Neecha Bhanga Raja ⭐⭐⭐⭐
**條件**：落陷行星，但守護星 / 高揚星在 Lagna 或月亮的角宮
**分類**：王者（弱轉強）
**解讀**：原本的弱點反而成為這輩子最強的能量來源 — 不是補償，是真正的轉化
**特別**：落陷的痛苦點變成主場，命主常在那個領域有非常規成就

### Vipareeta Raja ⭐⭐⭐
**條件**：6/8/12 宮主互相落在 6/8/12 宮
**分類**：王者（凶轉吉）
**解讀**：敵人 / 困難 / 損失反而成就你 — 透過危機、轉化、處理混亂局面而崛起
**注意**：不是「順風順水」，是「靠處理難題上來」

### Dharma-Karmadhipati ⭐⭐⭐⭐
**條件**：9 宮主和 10 宮主合相或互望
**分類**：王者 / 事業
**解讀**：事業帶來福德 / 福分助事業 — 升遷、貴人、領導機會

### Kahala ⭐⭐⭐
**條件**：4 宮主和 9 宮主合相或互望
**解讀**：家庭穩定 + 學識深厚 — 靠根基和長輩貴人崛起

## Dhana Yoga（財富格局）

> **重要原則**：多組 Dhana yoga 同時成立 = 財富來源多元 + 累積層次深。單一 Dhana yoga 也算，但越多組越穩。

| Yoga | 連結宮主 | 解讀重點 |
|------|---------|---------|
| **Lakshmi** ⭐⭐⭐⭐ | 9 宮主強勢 + 金星強勢 + 9 宮主在角宮 | 財富女神格局 — 配偶帶運、整體幸福 |
| **Dhana 1-2** ⭐⭐⭐ | 1 + 2 宮主連結 | 自我直接帶財 — 個人努力即現金流 |
| **Dhana 1-5** ⭐⭐⭐ | 1 + 5 宮主連結 | 自我帶來智慧財 / 創意 / 投資收益 |
| **Dhana 1-9** ⭐⭐⭐⭐ | 1 + 9 宮主連結 | 自我帶來福德財 — 老天賞飯吃型 |
| **Dhana 1-11** ⭐⭐⭐⭐ | 1 + 11 宮主連結 | 自我直接連結收入管道 — 親力親為帶財 |
| **Dhana 2-5** ⭐⭐⭐ | 2 + 5 宮主連結 | 言語 / 智慧 / 教學變現 |
| **Dhana 2-9** ⭐⭐⭐⭐ | 2 + 9 宮主連結 | 家族 / 福德積累的財富 |
| **Dhana 2-11** ⭐⭐⭐⭐ | 2 + 11 宮主連結 | 正財累積、收入來源穩定、口才換錢 |
| **Dhana 5-9** ⭐⭐⭐⭐ | 5 + 9 宮主連結 | 前世福德帶來財富、創意 / 子女 / 投資管道順 |
| **Dhana 5-11** ⭐⭐⭐ | 5 + 11 宮主連結 | 創意 / 子女 / 投機帶來長期收益 |
| **Dhana 9-11** ⭐⭐⭐⭐ | 9 + 11 宮主連結 | 福德直接化為長期收益 — 越老越富 |

## Parivartana Yoga（互換）⭐⭐⭐⭐

**條件**：兩顆行星位於彼此的星座

**三種類型**（依宮主性質判斷，需要查上升星座）：

| 類型 | 觸發 | 強度 |
|------|------|------|
| Maha Parivartana | 角宮主 + 三方宮主互換 | 王者級 — 超強 Raja Yoga |
| Khala Parivartana | 一般宮主互換 | 起伏型 — 兩個領域動盪共振 |
| Dainya Parivartana | 6/8/12 宮主和其他主互換 | 困難 — 兩個領域同時陷入 |

**解讀重點**：兩顆星管的領域**深度連動** — 升降轉折一起發生，互相帶旺或帶衰

## 其他特殊 Yoga

### Saraswati ⭐⭐⭐⭐
**條件**：水、木、金三者都在角 / 三方宮且強勢（高揚 / 廟旺）
**解讀**：學識 / 藝術 / 智慧 / 教育成就

### Kalanidhi ⭐⭐⭐
**條件**：木星在 2 / 5 宮且與水星 / 金星合或互望
**解讀**：藝術 / 音樂 / 學識 / 教育成就 / 受智者尊重

### Maha Bhagya（男性版）⭐⭐⭐⭐⭐
**條件**：太陽 / 月亮 / 上升都在奇數星座
**解讀**：整體運氣好 / 家境穩定 / 長壽 / 有貴人

### Kala Sarpa ⭐⭐
**條件**：所有 7 行星都在 Rahu-Ketu 軸的同一側
**性質**：雙面 — 凶中帶吉
**解讀**：強烈命運感 / 起伏大 / 特定領域非常規成就 / 情感連結弱
**特別**：常見於知名人物、突破常規的人

## 警示 Yoga / Dosha（凶）

### 月亮 / 收入類

| Yoga | 條件 | 重點 |
|------|------|------|
| **Kemadruma** ⚠️ | 月亮孤立（2/12 無星 + 月亮非角宮） | 情緒孤獨、需刻意建立支持系統 |
| **Shakata** ⚠️ | 月木 6/8 軸 | 福氣斷續、不要把希望寄託單一來源 |
| **Daridra** ⚠️ | 11 宮主在 6/8/12 | 收入易受阻、需謹慎資產配置 |

### 婚姻 / 親密關係

| Yoga | 條件 | 重點 | 破解 |
|------|------|------|------|
| **Mangal Dosha** ⚠️⚠️ | Mars 在 1/4/7/8/12 | 婚姻挑戰：配偶火爆、衝突多、結婚晚、對方家庭難搞 | Mars 廟旺（Aries/Scorpio）/ 高揚（Cap）= 已破解 |
| **Karako Bhava Nashaya (Venus)** ⚠️ | Venus 在 7 宮 | 婚姻 karaka 自傷 — 過度浪漫期待 vs 現實落差，配偶關係容易反覆 | 看 7 宮其他配置補強 |

### 信仰 / 父母 / 業力

| Yoga | 條件 | 重點 |
|------|------|------|
| **Guru Chandal Yoga** ⚠️⚠️ | Jupiter + Rahu 或 Jupiter + Ketu 同宮 | 對傳統信仰系統的衝突 / 反叛、精神導師議題、靈修上深度但古怪、與長輩在價值觀上拉扯 |
| **Pitra Dosha** ⚠️⚠️ | Sun + Rahu/Ketu 同宮 | 祖先 / 父系業力未了、父親或長輩關係挑戰、繼承類議題、需透過儀式 / 修行清業 |
| **Grahan Yoga (Moon)** ⚠️ | Moon + Rahu/Ketu 同宮 | 母親 / 情緒相關業力、安全感被遮蔽、母系挑戰 |

### 子女 / 創造

| Yoga | 條件 | 重點 |
|------|------|------|
| **Karako Bhava Nashaya (Jupiter)** ⚠️ | Jupiter 在 5 宮 | 子女 karaka 自傷 — 求子困難、子女緣薄、創意輸出不順 |

### 內在衝突

| Yoga | 條件 | 重點 |
|------|------|------|
| **Vish Yoga** ⚠️⚠️ | Saturn + Moon 同宮 / 互望 | 情緒沉重、容易內耗 / 抑鬱、母系或家庭氛圍嚴肅、安全感建立困難 |
| **Mars-Saturn Conflict** ⚠️ | Mars + Saturn 合相 / 互望 | 推進力 vs 紀律的反覆拉扯，做事容易自我消耗。合相 > 互望強度 |

### 行星力量受損

| 標記 | 條件 | 重點 |
|------|------|------|
| **Combust（焦傷）** ⚠️ | 行星距太陽 < 焦傷距（Mer 14° / Ven 10° / Mars 17° / Jup 11° / Sat 15°）| 該行星力量被太陽光遮，廟旺 / 高揚也救不了完全 — 主管領域要花更多力氣才發揮 |

## 使用指南（給 sub-agent）

### 報告中怎麼帶出 yoga

| 情境 | 做法 |
|------|------|
| 用戶問「我有幾個 yoga」 | 先給分類速覽（從 `分類彙整` 取數量 + 名稱） |
| 用戶問財運 | 列出所有財富分類 yoga + Lakshmi / Dhana 系列 |
| 用戶問事業 | 列出 Raja yoga + Dharma-Karmadhipati |
| 用戶問感情 | 看 7 宮 + 7 宮主，配合 Yoga 中跟伴侶有關的（Lakshmi、Malavya） |
| 一般人物觀察 | 帶 5 大人物 yoga（如果有），是這個人最外顯的天賦 |

### 解讀紅線

- ❌ 「有 X yoga = 自動成功」 — yoga 是潛力，要 Dasha 啟動
- ❌ 只看 yoga 不看 Dasha 階段
- ❌ 把警示 yoga 講成「會很慘」 — 講「要注意什麼 + 怎麼破解」
- ✅ 「有 X yoga + 現在 Y dasha 啟動 = 這幾年是 X 領域發功期」
