### 十一曜相喜相怕（相生相剋）

這是斷盤核心：**水喜金、金喜土、土喜火、火喜木、木喜水**（相生為喜）；反向為怕（相剋）。

- 例：太陽（火）喜歲星（木）同宮或拱照 → 木生火 → 增強元神
- 例：太陰（水）怕鎮星（土）相沖 → 土剋水 → 情緒與財運受損

### 三主定義（斷盤第一步）

**三主強弱判斷**：

- 廟 / 旺 = **強**（三主得地，格局高）
- 平 = **中**
- 落 / 陷 = **弱**（三主失地，需其他吉星救援）

**三主朝陽格**：若三主皆在命宮、官祿宮、遷移宮三合之內且廟旺 → 富貴壽考的頂級吉格。

### 廟旺落陷效力

- **廟**：最強位置，此星主管的領域是天生優勢，直接寫「這是你這輩子 X 領域的底牌」
- **旺**：接近最強，優勢明顯但不如廟
- **平**：無加成無減分，該星能量普通
- **落**：力量偏弱，相關領域容易費力不討好
- **陷**：最弱，該領域容易持續受挫，需靠吉星三合或拱照化解

### 斷命 SOP（六步驟，固定順序）

- **刑（90°）**：內在衝突，需主動調和

## 輸出原則

- **白話優先**：七政四餘術語多且古典，首次出現必須括號加白話解釋
- **三主是靈魂**：三主強弱不講等於沒講七政四餘
- **只報發現，不報空值**：空宮跳過、「平」的星曜只在總覽表格列出
- **不包裝**：廟就說強，陷就說弱，不硬湊正面解讀
- **後果導向**：每個發現都要連結到「所以你的生活會怎樣」
- **和西洋占星區隔**：強調恆星黃道與命格高下的判斷，避免讀者混淆為西洋星座
- **二十八宿是特色**：這是七政四餘獨有的精細度，命宮與日月所在宿要花篇幅解
- **格局是重點**：有格局的盤要重點說明，沒格局就誠實講「本盤無特殊格局，屬於平實命造」
- **斷語要具體**：不要只寫「你財運不錯」，要寫「太白廟在財帛宮 → 你靠專業技能或金融相關領域賺錢，不適合投機」
