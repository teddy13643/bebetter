# 八字大運流年分析

使用 `bebetter bazi-fortune` tool 計算個人大運流年運勢。

## 參數解析

從使用者輸入中提取以下參數（缺少的就問）：

| 參數           | 必須 | 格式            | 說明                            |
| -------------- | ---- | --------------- | ------------------------------- |
| pillars        | 是   | 6 或 8 個中文字 | 八字四柱，如 `庚午壬午辛亥甲午` |
| gender         | 是   | `男` 或 `女`    | 影響大運順逆                    |
| birth_date     | 是   | `YYYY-MM-DD`    | 計算起運歲，如 `1990-06-15`     |
| target_year    | 否   | 數字            | 分析起始年，預設今年            |
| forecast_years | 否   | 數字            | 預測年數，預設 10               |

如果使用者只說「幫我看今年運勢」但沒給八字，問他要出生年月日時（西曆），然後用 `bebetter natal` 取得八字四柱，再用取得的四柱呼叫 `bebetter bazi-fortune`。

## 執行

呼叫 `bebetter bazi-fortune`，傳入解析好的參數。

## 輸出格式

收到結果後，用以下結構整理給使用者：

### 1. 個盤摘要（簡短）

- 日主、五行強弱、用神/忌神（一兩句話）
- 格局：講「{格局}（{取格依據}）— {成敗}」，用白話說明這個格代表的人生主軸／社會定位。`疑似外格` 有值時補一句「結構疑似 X，需人工複核」，不要直接斷成外格

### 2. 大運走勢

- 列出大運總覽，標記當前所在大運
- 說明當前大運對日主的影響

### 3. 逐年流年解讀

每一年用以下格式：

```
**{年份} {干支}年**（{納音}）— {喜忌判定}
- 十神：天干{十神}、地支{十神}
- 命盤交互：{列出重點}
- 大運交互：{列出重點}
- {如有觸發神煞，列出}
→ 白話解讀（2-3 句，講對事業/財運/感情/健康的影響）
```

### 4. 關鍵年份提醒

把標記為關鍵的年份單獨拉出來，用白話說明需要注意什麼。

## 解讀原則

- 用白話解釋十神和神煞的含義，不要只列術語
- 格局成敗正負對稱講：成格說明這個結構的優勢與適合走的路，破格／待細推誠實講限制與不確定，不要只報成格讓人誤以為命格全好。`成敗` 是結構傾向不是鐵口，引擎標「待細推」就說需配合刑沖虛實，不要替它斷死
- 喜用神年份強調把握機會的方向
- 忌神年份強調需要注意的面向，但不要過度恐嚇
- 結合大運 + 流年的疊加效果來判斷（大運為底色，流年為觸發）
- **結構分析，不是論斷**：你拿到的是干支結構，不是這個人的人生。講的是「這個結構容易產生什麼傾向」，不是「你今年一定會怎樣」。用「容易」「傾向」「結構上偏向」，語氣像機率分布而非宣判
