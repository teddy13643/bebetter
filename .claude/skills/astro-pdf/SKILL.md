# 占星報告 PDF 生成（Pencil MCP）

將對話中最近一次占星報告（`/bb-astro`、`/astro`、`/vedic` 等）轉成手機友善的精美 PDF。

## 前提

對話中必須已有完整的占星報告輸出。如果沒有，提醒用戶先跑占星 skill。

## 設計規格

- **寬度**：390px（iPhone 標準，手機閱讀優化）
- **風格**：深黑底 #0A0A0A + 金色點綴 #C9A962（Elegant Luxury）
- **字體**：標題 Cormorant Garamond / 內文 Inter 15px / 度數 JetBrains Mono
- **行高**：內文 1.85，結尾信 2.0
- **間距**：section gap 24-32px，卡片 padding 20px，左右 padding 24px

## 執行流程

### 1. 擷取報告內容

從對話中找到最近一次占星報告的完整輸出，辨識結構：

- 出生資料、太陽/月亮/上升
- 行星位置表
- 敘事段落（你是誰）
- 五大主題（每個主題都含建議）
- 行運年度故事（如果有 Part 2）
- 關鍵月份、結尾信

### 2. 在 Pencil MCP 設計

用以下色彩系統和元件結構，在 Pencil MCP 建立手機版版面。

#### 色彩系統

| 用途     | 色碼              |
| -------- | ----------------- |
| 背景     | #0A0A0A           |
| 卡片背景 | #141414           |
| 金色主色 | #C9A962           |
| 金色透明 | #C9A96240         |
| 金色背景 | #C9A96215         |
| 內文     | #d4d0c8           |
| 次要文字 | #848484           |
| 弱文字   | #6A6A6A           |
| 最弱文字 | #4A4A4A           |
| 分隔線   | #1A1A1A / #2A2A2A |
| 警示背景 | #8b203515         |
| 警示邊框 | #8b203550         |
| 警示文字 | #e8778a           |

#### 元件結構

**封面**（height: 720, 垂直置中）

```
✦ ★ ◇ ★ ✦（裝飾，金色透明）
標題（Cormorant Garamond 42px 金色）
副標題（18px 白色）
英文副標（Inter 13px 灰色斜體）
─── 金色分隔線 ───
出生資料（Inter 14px 灰色）
三張卡片橫排（fill_container，#141414 背景 + 金色邊框）
  每張：符號 + LABEL + 星座名
```

**Section 標題**（置中）

```
PART I / PART II（Inter 10px 金色 letterSpacing:4）
中文標題（Cormorant Garamond 26px 白色）
─── 金色分隔線 ───
```

**行星位置表**

```
表頭：天體(60) | 星座(fill) | 度數(70) | 宮(36) | ℞(20)
  - 表頭背景 #C9A96215，底線 #C9A96240
  - 天體名白色，其餘灰色，度數用 JetBrains Mono
  - 逆行 ℞ 用金色 fontWeight:600
  - 奇偶行交替 #FFFFFF03
  - 十大行星列完後，加一條 #1A1A1A 分隔線
  - 接著列其他星體（北交、南交、莉莉絲、凱龍、穀神、智神、婚神、灶神）
  - 其他星體的天體名用 #848484（次要色），與主行星區隔
```

**敘事段落**

```
小標題（Cormorant Garamond 22px 金色）
段落文字（Inter 15px #d4d0c8 lineHeight:1.85 textGrowth:fixed-width width:fill_container）
```

**主題卡片**（#141414 背景 + 邊框）

```
重點主題（感情/工作）：金色邊框 #C9A96240
一般主題（金錢/健康/社交）：灰色邊框 #2A2A2A
每張卡片：
  主題標題（Cormorant Garamond 16px 金色，帶 ♡ 或 ◆）
  描述段落（Inter 15px #d4d0c8）
  建議標題（Inter 14px 金色 fontWeight:500）
  建議內容（Inter 14px #848484，每條 → 開頭）
```

**年度主題引言**（左邊框 3px 金色 + 金色背景）

```
標題（Cormorant Garamond 22px 金色）
描述（Inter 15px #d4d0c8）
```

**行運時間軸卡片**（#141414 + 左邊框 3px 金色透明）

```
時間標題（Cormorant Garamond 15px 金色）
描述（Inter 15px #d4d0c8）
建議（Inter 14px 金色，→ 開頭）
```

**關鍵月份提示**

```
把握月份：金色背景 #C9A96215 + 金色邊框
謹慎月份：紅色背景 #8b203515 + 紅色邊框，標題 #e8778a
```

**結尾信**（#141414 卡片 + 金色邊框）

```
每段（Cormorant Garamond 16px lineHeight:2）
第一段白色，後續段落 #FFFFFF99
```

**Footer**

```
金色分隔線
"Generated by BeBetter Astrology System"（Inter 10px #4A4A4A）
```

### 3. 建構順序

用多個 `batch_design` 呼叫，每次 ≤ 25 operations：

1. `find_empty_space_on_canvas` → 建主 frame（390px 寬，placeholder:true）
2. 封面區塊（含三張卡片）
3. Part 1 標題 + 行星表表頭
4. 行星表 rows（分批，每批 4-5 行）
5. 「你是誰」敘事段落
6. 五大主題卡片（感情 + 工作）
7. 五大主題卡片（金錢 + 健康 + 社交）
8. Part 2 標題 + 年度引言 + 行運故事
9. 行運故事續 + 關鍵月份
10. 結尾信 + footer + 移除 placeholder

每個步驟完成後不需要截圖驗證，最後匯出前截一次確認即可。

### 4. 匯出 PDF

```
export_nodes(nodeIds: [主frame ID], format: "pdf", outputDir: "~/Documents/workspace")
```

匯出後 rename 為 `bb-astro-{year}.pdf` 並 `open` 打開。

## 輸出

- PDF：`~/Documents/workspace/bb-astro-{year}.pdf`

## 注意事項

- 如果 Pencil MCP 沒有開啟文件，先 `open_document("new")`
- 如果 schema 未載入，`get_editor_state(include_schema: true)`
- 所有文字都要設 `fill`，否則不可見
- 使用 `textGrowth: "fixed-width"` + `width: "fill_container"` 讓文字自動換行
- 不需要呼叫 `get_guidelines` 或 `get_style_guide`，設計規格已固定在此 skill 中
